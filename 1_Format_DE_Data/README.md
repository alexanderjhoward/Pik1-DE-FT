# Cleaning and exploring *Pikh-1* directed evolution data

## Background
Following the directed evolution of *Pikh-1*, next-generation sequencing was used to survey the change in sequence abundance before and after selection via FACS. In this portion of the project, I explored the development of an "enrichment score" to quantify variant fitness and develop datasets to identify the best modeling approaches towards predicting these enrichment scores. 

## Run script
I ran the **clean_facs_data.R** script to generate exploratory datasets to test modeling approaches, plot out distributions of reads/scores, and create a final set of sequences/scores for the full-scale modeling.
